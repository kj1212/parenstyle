# 괄호 → 문자 스타일

원고의 `(괄호)`를 벗기고, 안쪽 글자에 인디자인 **문자 스타일**을 물린 채로
클립보드에 담는다. 본문(괄호 밖)에는 **단락 스타일 + 문자 스타일**을 함께 물린다.
인디자인이 실제로 쓰는 방식 그대로다. (괄호 안 위첨자는 같은 문단 안 인라인, 문자 스타일만 다르게.)

괄호 안이 **한자냐 숫자냐 영문이냐**에 따라 서로 다른 문자 스타일을 줄 수 있다.

맥과 Windows 둘 다 돈다. 딸린 라이브러리 없이 파이썬만 있으면 된다.

```
공자(孔子)는 이렇게 말했다(주석1).
 │      │                 │
 │      └ 한자 → '한자윗첨자' └ 나머지 → '윗첨자'   (괄호 안 = 위첨자 문자 스타일)
 └ 본문 → 단락 '[기본 단락]' + 문자 '본문'          (괄호 밖 = 단락 + 문자 스타일)
```

---

## 실행

| | |
|---|---|
| 맥 | **`실행-맥.command`** 더블클릭 |
| Windows | **`인디자인_실행-윈도우.bat`** 더블클릭 |

### ★ 맥은 반드시 이 launcher 로

맥에 딸려 오는 파이썬은 **Tk 8.5.9** 라는 오래전에 버려진 판을 쓴다.
요즘 macOS 에서 이 판은 **창을 빈 화면으로 그린다.** 실제로 그렇게 됐었다.
`실행-맥.command` 는 Tk 8.6 이상인 파이썬을 찾아서 띄운다. 없으면:

```
brew install python-tk
```

Windows 는 python.org 판이면 Tk 8.6 이 딸려 오므로 그냥 된다.
설치할 때 **"Add python.exe to PATH"** 를 켤 것.

## 쓰기 전에 — 인디자인 설정 한 번

**인디자인 > 설정(환경설정) > 클립보드 처리**
→ "다른 응용 프로그램의 텍스트 및 표 붙여넣기" 를 **"모든 정보"** 로.

여기가 "텍스트만"이면 인디자인이 서식을 통째로 버린다.
**이걸 안 하면 아무것도 안 된다.** (맥·Windows 공통)

## 쓰는 법

1. 원고를 붙여넣는다 (또는 **클립보드에서 가져오기**)
2. 스타일 이름을 인디자인 문서에 있는 이름과 **똑같이** 적는다
3. **변환해서 클립보드에 담기**
4. 인디자인에 붙여넣는다

처음이면 **보기 예시 넣기** 를 눌러 보면 어떻게 도는지 바로 보인다.
아래 상태줄에 `괄호 5곳 — 한자 2, 나머지 3` 처럼 갈래별로 세어 보여준다.

변환될 `(괄호)`는 원고에서 **갈래별 색으로 칠해진다** (한자 파랑, 숫자 초록, 영문 주황,
한글 보라, 나머지 살구). 눈으로 어디가 바뀔지 미리 확인할 수 있다.

## 갈래 나누기

`기본` 은 언제나 쓰인다. 아래 넷은 켠 것만 따로 빠진다.

| 갈래 | 걸리는 것 | 안 걸리는 것 |
|---|---|---|
| 한자 | `孔子` `論語 卷一` | `漢字a` (섞이면 나머지로) |
| 숫자 | `12` `１２` `1-2` | `12쪽` |
| 영문 | `Kant` `abc` | `Kant1` |
| 한글 | `가나다` | `주석1` |

빈칸·마침표·쉼표·가운뎃점·붙임표는 무시하고 가른다.
섞여 있으면 **나머지** 로 간다.

## 곁다리

- **한글 뒤 한자 병기** — `한글 뒤 붙은 한자도 위첨자로` 를 켜면, 괄호 없이 `준浚`·`정약용丁若鏞`
  처럼 **한글 바로 뒤에 붙은 한자**를 찾아 '한자' 문자 스타일(위첨자)로 물린다.
  (문두·공백 뒤 한자는 본문으로 둔다. 잘못 걸리면 그 한자를 골라 **선택 → 예외**)
- **예외 처리** — 색칠된 `(괄호)`·병기 한자 중 일부를 드래그로 골라 **선택 → 예외** 를 누르면
  변환하지 않고 그대로 둔다(회색·취소선). **예외 해제** 로 되돌린다
- **괄호를 남긴다** — 지우지 않고 서식만 입힌다
- **단락 스타일 끄기** — 붙여넣는 자리 스타일을 그대로 물려받는다
- **RTF 파일로 저장** — 인디자인 **파일 > 가져오기(⌘D)** 로 넣는다
- **저장해 둔 설정** — 책마다 다른 스타일 쓸 때. 이름 붙여 저장하고 골라 쓴다
- ⌘Return / Ctrl+Return 으로도 변환된다
- 그냥 창만 닫아도 마지막 상태는 자동 저장된다

## 파일

| 파일 | 하는 일 |
|---|---|
| `gui.pyw` | 창 |
| `engine.py` | 괄호를 찾아 갈래를 가르고 RTF 를 짓는다 |
| `clipboard_rtf.py` | 클립보드에 얹는다 (맥 = NSPasteboard, Windows = Win32) |

설정 저장 위치:
- 맥 `~/Library/Application Support/ParenStyle/settings.json`
- Windows `%APPDATA%\ParenStyle\settings.json`

## 어떻게 되는 건가

클립보드는 한 덩어리가 아니라 **같은 내용을 여러 서랍에 따로** 담는다.
이 프로그램은 두 서랍을 채운다.

```
public.rtf / CF_RTF    {\rtf1 ... {\*\cs1 \additive \super 한자윗첨자;}
                                  {\*\cs2 \additive \super 윗첨자;} ...}
평문                    괄호만 벗긴 맨 글자
```

인디자인은 "모든 정보" 설정일 때 RTF 서랍을 열고, 스타일시트의 **이름**으로
문서에 이미 있는 스타일을 찾아 붙인다. 이름이 어긋나면 같은 이름의 스타일을
새로 만들어버리니, 이름은 정확히 적어야 한다.

`\super` 를 함께 넣어 두었다. 이름 매칭이 실패해도 최소한 윗첨자로는 보인다.

## 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 창이 빈 화면이다 | 맥 기본 파이썬(Tk 8.5). `실행-맥.command` 로 띄울 것 |
| 서식 없이 평문만 들어온다 | 인디자인 클립보드 처리가 "텍스트만" |
| `윗첨자 복사 1` 같은 게 새로 생긴다 | 스타일 이름이 문서와 다르다 |
| 붙여넣어도 아무 반응 없다 | 문자 도구로 텍스트 프레임 안에 커서를 세웠는지 |
